## The entry

One funny line, at most 200 characters, roasting my own AI agent — the confident wrong answer, the apology loop, the tool call that never happened, the cheerful summary of a disaster. Mine goes after the agent's most loyal habit: burning through its whole context window and then forgetting what it was building in the first place.

> I gave my agent one clear instruction and a full context window; it used the window, forgot the instruction, and asked me what we're building.

## Run it

Requires Node 22.18 or later (the grader runs Node 22.23.4).

```sh
node main.ts
```

This writes the roast line to `/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set). The file holds exactly the single line, 142 characters plus a trailing newline — inside the 1–200 character gate.
